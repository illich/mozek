# Round 2 notes: FastMCP, MCP authorization, auth vendors (checked 2026-10-29)

| # | Topic | Finding and source |
|---|---|---|
| 1 | FastMCP version | 4.1.4 released 2026-10-26; 4.0.0 on 2026-08-31 ("Server-initiated sampling and roots are removed", `ctx.elicit()` old-protocol-only, hardened OAuth consent, issuer validation and JWT verification); 3.x still patched (3.4.11, 2026-10-20). https://github.com/jlowin/fastmcp/releases ; https://pypi.org/project/fastmcp/#history |
| 2 | GoogleProvider | OAuth proxy "since Google doesn't support Dynamic Client Registration". Settings `client_id`, `client_secret`, `base_url`, `required_scopes=["openid", ".../userinfo.email"]`, default `redirect_path="/auth/callback"`. 4.x adds `client_storage`, `jwt_signing_key`, `require_authorization_consent`, `forward_resource=True`, `fastmcp_access_token_expiry_seconds`, `extra_authorize_params`, `enable_cimd=True`. https://gofastmcp.com/integrations/google ; https://gofastmcp.com/servers/auth/oauth-proxy ; https://raw.githubusercontent.com/jlowin/fastmcp/main/fastmcp_slim/fastmcp/server/auth/providers/google.py |
| 3 | Caller's email | `get_access_token().claims.get("email")` still works; dependency forms `CurrentAccessToken()` and `TokenClaim("email")`. Stored claims: sub, aud, email, email_verified, name, picture, locale; no `hd`. Role gating via `@mcp.tool(auth=...)` (3.0) and `require_roles` (4.0). https://gofastmcp.com/servers/dependency-injection.md ; https://gofastmcp.com/servers/authorization.md |
| 4 | Hosted domain | No built-in `hd` or allowlist. `extra_authorize_params={"hd": "zuri.com"}` is possible but Google says `hd` is a UI hint and "You must check this claim when restricting access". Enforce on `email` + `email_verified`. https://developers.google.com/identity/openid-connect/openid-connect |
| 5 | Production storage | `client_storage` and `jwt_signing_key` "are required for production deployments"; default disk store is for development; use Redis or DynamoDB via `py-key-value-aio`; wrap in `FernetEncryptionWrapper` or "upstream OAuth tokens are stored in plaintext". https://gofastmcp.com/servers/storage-backends.md |
| 6 | Evidence with Claude.ai | Docs show `allowed_client_redirect_uris=["https://claude.ai/api/mcp/auth_callback"]`. Issue #1919 "Google OAuth doesn't work for Claude.ai" (400 instead of 401 `invalid_client`) fixed by PRs #1923 and #2538; reporter "confirmed the flow worked on both Claude.ai and Claude Code" with GoogleProvider. https://github.com/jlowin/fastmcp/issues/1919 . PR #4206 (2026-06-27) made metadata advertise `client_id_metadata_document_supported=True` and `"none"`, so Claude chooses CIMD instead of DCR. https://github.com/jlowin/fastmcp/pull/4206 . No FastMCP-specific Team org-wide or mobile write-up found; Anthropic says all its clients share one OAuth client. Open Claude-side bug: anthropics/claude-ai-mcp #476 (since 2026-06-21), connectors "Connected" but tools never offered to the model on claude.ai web, FastMCP and non-FastMCP users, no staff reply. https://github.com/anthropics/claude-ai-mcp/issues/476 |
| 7 | MCP spec | Current revision 2026-07-28. CIMD "SHOULD"; "Dynamic Client Registration is deprecated"; PRM (RFC 9728) MUST; RFC 8707 `resource` MUST in authorization and token requests; PKCE S256 mandatory. Also: stateless protocol (no `initialize`, no `Mcp-Session-Id`), mandatory `server/discover`, elicitation and sampling replaced by Multi Round-Trip Requests. https://modelcontextprotocol.io/specification/versioning ; https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization ; https://modelcontextprotocol.io/specification/2026-07-28/changelog |
| 8 | Official SDKs | Python SDK v2 (2.3.0, 2026-10-02): "The SDK gives you the resource-server half: verify, advertise, refuse. It does not give you a login page, a consent screen, or a token." https://py.sdk.modelcontextprotocol.io/run/authorization/ . TypeScript SDK v2: `ProxyOAuthServerProvider` frozen in `server-legacy`. https://ts.sdk.modelcontextprotocol.io/v2/serving/authorization.html |
| 9 | Cloudflare | `workers-oauth-provider` MIT, targets MCP 2026-07-28, CIMD and DCR. https://github.com/cloudflare/workers-oauth-provider . `remote-mcp-google-oauth` demo has `HOSTED_DOMAIN`; Claude Desktop via `mcp-remote` only. https://github.com/cloudflare/ai/tree/main/demos/remote-mcp-google-oauth |
| 10 | Hosted authorization servers | WorkOS AuthKit: CIMD off by default, free to 1M MAU (https://workos.com/docs/authkit/mcp , https://workos.com/pricing). Stytch Connected Apps: CIMD, free 10,000 MAU (https://stytch.com/docs/guides/connected-apps/mcp-server-overview). Auth0 "Auth for GenAI": DCR and manual CIMD, free 25,000 MAU (https://auth0.com/ai/docs/mcp/intro/why-auth-for-mcp). Descope Agentic Identity Hub: free 7,500 MAU (https://docs.descope.com/agentic-identity-hub). Scalekit: free to 1M (https://docs.scalekit.com/guides/mcp/oauth). Clerk: CIMD GA 2026-09-17 (https://clerk.com/docs/expressjs/guides/ai/mcp/build-mcp-server). None documents Claude.ai custom connectors explicitly. |
| 11 | Other frameworks | punkpeye/fastmcp (TypeScript, 4.23.8, MIT) has `GoogleProvider` and an OAuth proxy; Vercel `mcp-handler` and `mcp-auth` are resource-server only. https://jsr.io/@punkpeye/fastmcp/doc/all_symbols ; https://github.com/vercel/mcp-handler ; https://mcp-auth.dev/ |
| 12 | Annotations, instructions, elicitation | `@mcp.tool(annotations=ToolAnnotations(title=..., readOnlyHint=True, openWorldHint=False))`; 4.0 always sets a title. `FastMCP("Name", instructions="...")`. Elicitation is old-protocol-only in 4.x and there's no evidence claude.ai web supports it for custom connectors. https://gofastmcp.com/servers/tools ; https://gofastmcp.com/servers/server ; https://gofastmcp.com/servers/elicitation |
