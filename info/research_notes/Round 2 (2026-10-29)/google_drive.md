# Round 2 notes: Google Drive, Docs, Sheets and OAuth facts (checked 2026-10-29)

Scope: re-verify the Drive → Markdown mirror assumptions against developers.google.com and Workspace blogs. "LU" = the page's "last updated" stamp. Third-party-only facts are marked (unverified).

| # | Claim | Status | Finding and source |
|---|---|---|---|
| 1 | `text/markdown` export is Docs-only | CONFIRMED | Export table lists Markdown under Google Docs only; Sheets get xlsx/ods/pdf/zip/csv/tsv, Slides pptx/odp/pdf/txt. https://developers.google.com/workspace/drive/api/guides/ref-export-formats (LU 2026-09-03). "exported content is limited to 10 MB": https://developers.google.com/workspace/drive/api/reference/rest/v3/files/export |
| 1b | Export handling of tables, images, footnotes, tabs | NOT FOUND officially | Third-party (unverified): headings get Pandoc-style `{#id}` anchors; images are embedded as base64 `data:` URIs at the end of the file. https://wayofmarkdown.com/markdown-in-google-docs ; https://www.zonca.dev/posts/2026-05-24-gdrivemd-tutorial . Base64 images count toward the 10 MB cap. The earlier claim that images are "dropped" is replaced by this. |
| 2 | Sheets CSV/TSV first sheet only; Sheets API for all tabs | CONFIRMED | "CSV first-sheet only", "TSV first-sheet only". `spreadsheets.values.batchGet` takes one range per tab and accepts `drive.file`. https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/batchGet . No Markdown export for Sheets exists. |
| 3 | Native `.md` in Drive/Docs | CHANGED (date and meaning) | Announced 2026-10-05 (not Oct 26): view, edit and collaborate on `.md` files directly in Docs and preview them in Drive, "without changing the file type"; not an export feature. https://workspaceupdates.googleblog.com/2026/10/preview-edit-and-collaborate-on-Markdown-files-natively-across-Drive-and-Docs.html . Docs may rewrite Markdown syntax on save (unverified): https://www.dsebastien.net/2026-10-21-google-docs-now-edits-markdown-files-natively/ |
| 4 | Docs tabs | CONFIRMED with caveat | Docs API `documents.get` needs `includeTabsContent=true`, otherwise only the first tab is returned. https://developers.google.com/workspace/docs/api/how-tos/tabs . Per-tab `files.export` is officially unsupported: https://dev.to/googleworkspace/exporting-individual-tabs-from-google-docs-as-pdfs-2903 ; https://issuetracker.google.com/379170478 . Whether the Markdown export concatenates all tabs is undocumented (verify). |
| 5 | `drive.file` semantics | CONFIRMED | Non-sensitive, per-file: files "that you open with an app or that the user shares with an app while using the Google Picker API". https://developers.google.com/workspace/drive/api/guides/api-specific-auth . Verification "is not mandatory" for non-sensitive-only apps: https://support.google.com/cloud/answer/9110914 . The grant is tied to the consenting user's token (Picker overview); no official background-access pattern; a service account sees only files shared with it (unverified, https://nango.dev/blog/fix-google-drive-api-404-file-not-found). |
| 6 | Restricted scopes and CASA | CONFIRMED, terminology changed | `drive`, `drive.readonly` etc. are restricted; "applications requesting access to restricted scopes must undergo an annual security assessment". https://support.google.com/cloud/answer/13465431 . Levels are now AL1/AL2, lab verified: https://appdefensealliance.dev/casa/casa-tiering . Cost about $540 per app per year (unverified): https://www.switchlabs.dev/post/casa-tier-2-tier-3-security-review-providers-pricing-and-the-cheapest-option . Internal apps: "Verification is not required"; unverified external apps are capped at 100 users. https://developers.google.com/identity/protocols/oauth2/production-readiness/overview |
| 7 | Push notification channel lifetimes | CONFIRMED | Max 86,400 s (1 day) for `files`, 604,800 s (1 week) for `changes`; default 3,600 s; payload-less. https://developers.google.com/workspace/drive/api/guides/push (LU 2026-09-17) |
| 8 | Quotas | CHANGED | Drive API quota units: 1,000,000 units/min per project, 325,000/min per user; `files.get` 5 units, `files.list` 100, download 200, update 50; applies to projects created on or after 2026-05-01. https://developers.google.com/workspace/drive/api/guides/limits . Sheets API: 300 reads/min per project, 60/min per user. https://developers.google.com/workspace/sheets/api/limits |
| 9 | Comments and suggestions | CHANGED (better) | Comments are not in exports (not documented, third-party says excluded). `comments.create` works but API comments render unanchored in the editors. https://developers.google.com/workspace/drive/api/guides/manage-comments . Docs API `batchUpdate` with `WriteControl.writeMode = SUGGEST` applies all updates as suggestions. https://developers.google.com/workspace/docs/api/how-tos/suggestions ; https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/batchUpdate |
| 10 | Google-hosted Workspace MCP servers | CONFIRMED Developer Preview | Drive server launched 2026-04-22, Docs and Sheets 2026-07-13, all still preview. Drive server requires `drive.readonly` + `drive.file`; no file allowlist; Claude.ai custom connector steps are documented. From 2026-11-11 requests from OAuth clients not flagged "Use this client for an AI-powered agent" are rejected. https://developers.google.com/workspace/guides/configure-mcp-servers ; https://developers.google.com/workspace/drive/api/guides/configure-mcp-server ; https://developers.google.com/workspace/release-notes |
| 11 | Picker API | CONFIRMED | Supported, no deprecation (LU 2026-10-12); needs API key, App ID (project number) and an OAuth token with `drive.file`; a website-restricted key must allow `https://docs.google.com/*`. https://developers.google.com/workspace/drive/picker/guides/web-picker |
| 12 | Service accounts | CONFIRMED with change | "Service accounts don't have storage quota and can't own files"; they can read files shared with them and be Shared Drive members. https://developers.google.com/workspace/drive/api/guides/about-shareddrives . Domain-wide delegation would need restricted scopes. |
| 13 | Tools | CHANGED | wikiGDrive active (last push 2026-08-18, MIT, whole Shared Drive). gdrivemd is two shell scripts around the `gog` CLI (https://github.com/zonca/gdrivemd). shanemcd/gcmd has `--all-tabs` (https://github.com/shanemcd/gcmd). Also niStee/gdocs-git-sync, MattFisher/md-gdoc, rsheyd/google-docs-markdown-sync. None combines Picker per-file selection with a git mirror. |
