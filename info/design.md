
This describes the full functionality design, so Phase 2+

Design should be quite similar to other services people are using these days:

Three main areas:

1. The frame - narrow left edge column and one-line upper bar.

    On the left, it contains icons:
    - Home icon - inside is the main overlook, covering what's happening everywhere the user has access
    - (DMs maybe as separate icon, to be decided later)
    - Project icons - then individual projects. Sorted by usage (by the individual user). If user has more than 5 projects, there is "..." icon covering projects 6+
    (then space)
    - Settings icon - in lower left, 2nd from bottom
    - User icon - lower left, 1st from bottom

    The upper row, just a search bar for now.


2. Left column (narrow)

    List of channels and conversations, roughly in chronological order.
    Also, in the project view, a files menu item.
    To be defined in detail later.

3. Right column (wide, occupyping typically 2/3 of widescreen monitor)

    The main content, usually a conversation

    Or in files, list of attached files on google drive, their maintainer and status (fresh = fully synced, outdated, not fetched yet,...)
